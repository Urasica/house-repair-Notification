2026-10-05(KST), 로컬 개발 DB의 M09 게시본 `ebf3dec4-3905-5932-b29e-9651f438a937`을 사용했다. gpt-5.4-mini·text-embedding-3-large/1536, promptVersion=chat-v1-extractive다.

- [합성 평가셋](evaluation-cases.json): 조문/별표 설명, 운영/혼합/불명확 문의, 미검증/누락 자료, 프롬프트 공격, 위험 표현, 입력 부족 12건.
- [최종 실제 평가](evaluation-report.json): 상태·답변 방식·생성 호출 여부·인용 위치·연락처 없음 검증. 승인된 설명에서만 실제 생성하며 답변 본문은 해시만 보관한다.
- [초기 평가](initial-evaluation-report.json): 제35조를 생성 가능하다고 잘못 기대한 사례를 보존한다. 실제 M09 게시본은 외부 참조 미검증으로 제외했고, 이 정책을 완화하지 않았다.
- [실제 회원 API](runtime-verification.json): 근거 생성·전체 별표/비고·재생·조회·맥락 변경·정리 확인. 비밀·원문 대화·개인 계정 정보는 포함하지 않는다.

평가 통과 범위는 검토 원문 선택·인용과 서버의 적격성 정책이다. 자유 재서술이나 LH 운영 판단의 정확도를 입증하지 않는다. 실제 호출은 비용을 발생시킬 수 있고 데이터 공유 혜택의 계정 자격은 확인하지 않았다. 보고서 generationTokens는 해당 관리 평가의 생성 호출만 집계하며 질문 임베딩·별도 HTTP smoke 사용량은 제외한다.
