# M09 지식 검토·검색 평가 기록

시작: 2026-10-04 · 완료: 2026-10-05(KST)

M08 원문과 M08A 실제 목록을 사용했다. 원문과 벡터는 접근 제한 파일/로컬 DB에 보관하며 이 디렉터리는 검토 범위와 합성 평가 질문·검증 결과만 포함한다.

- [review.json](review.json): 원문 설명·관련 법령 참고에 한정한 서비스 적격성 검토. 사람의 법률/LH 운영 승인 아님.
- [evaluation-cases.json](evaluation-cases.json): 실제 목록의 44개 증상과 F10a~F10c·불명확/미확인/누락 조문 등의 9개 경계 질문, 총 53개.
- [evaluation-report.json](evaluation-report.json): 최종 실제 OpenAI 임베딩과 pgvector 검색 결과.
- [runtime-verification.json](runtime-verification.json): 로컬 API의 준비 상태·설문 인용·동일 요청 재생 검증. 계정/상담 토큰은 포함하지 않음.
- [초기 평가 기록](releases/initial-evaluation-report.json): 별표에서 상위 조문으로의 역방향 연결 보완 전 51건 평가. 해당 초기 BUILDING 묶음은 게시하지 않았음.

최종 릴리스: `ebf3dec4-3905-5932-b29e-9651f438a937`, 카탈로그: `m08a-20261004-v2`. 게시 시각: `2026-10-04T17:31:14.749439Z`(2026-10-05 02:31:14 KST). 임베딩: `text-embedding-3-large`, 명시적 1536차원, cosine 정확 검색.

총 49개 청크는 40개 조문·3개 별표·총칙 5개 및 부칙 전체 1개다. 제10조↔별표 2, 제42조↔별표 3, 제43조↔별표 4를 연결하며 총칙/부칙은 필수 문맥으로 보존한다. 상위 조문/별표/문맥 중 하나가 미승인·철회·기한 만료·해시 불일치이면 근거 묶음을 사용하지 않는다.

53건의 근거 묶음 recall@5와 상태 정확도는 각각 100%, 운영 문의에 법령을 APPLICABLE로 취급한 경우는 0건이다. 이 평가는 **확인된 카탈로그 증상 또는 명시적 조문 번호로 후보를 제한하는 현재 검색 계약**을 검증한다. 임의의 자유 질문, 한국어 전반, small 대비 large의 우월성 또는 생성 답변 정확도를 입증하지 않는다. 챗봇 생성 평가는 M10이다.

최초 문서 임베딩 16,190토큰. 연결 보완 후 49개 벡터를 재사용하여 추가 문서 임베딩은 0토큰이다. 평가 질문은 51건 1,431토큰을 두 차례, 최종 53건 1,473토큰 사용하여 관리 명령에서 확인한 합계는 20,525토큰이다. 그 이후 실제 설문 API 확인 1회의 질문 임베딩 사용량은 이 합계에 포함하지 않았다. 총비용 한도는 사용자 지시에 따라 두지 않았고 공급자의 요청 크기·시간 제한은 유지한다.

현재 자료는 LAW_CRITERIA뿐이다. 일반 설문은 법령을 RELATED로 인용하며 NEED_CONFIRMATION을 유지한다. 명시적 법령 설명은 확인된 조문에만 APPLICABLE을 허용하며, 외부 규정 미검증·별표 4 손상 문구·누락 조문이 포함된 설명은 확인 안내로 남긴다. 운영 문의와 혼합 문의에는 LH_OPERATION이 필요하다.

재현 절차와 제한은 [지식 반입·검색 운영 안내](../../../docs/12-knowledge-publication.md), 완료 기록은 [M09 기록](../../../progress/04-m09-knowledge-review.md)을 따른다.
