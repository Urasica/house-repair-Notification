# MVP 개발 진행 안내

작성: 2026-10-03 · 갱신: 2026-10-05 · 현재 상태: M01~M10 완료 · 다음 M11

기준: [전체 설계](../docs/README.md) · 작업 상세: [순서별 MVP 체크리스트](01-mvp-tasks.md)

현재 공통 계약·Docker 실행 환경·13개 DB 테이블·회원 인증·목록 검증/게시·상담/설문/결과/이력/삭제 API와 프론트 화면을 구현했다. 실제 PostgreSQL + pgvector 시험 74건을 포함한 백엔드 219건을 검증했다. M10 프론트 40건과 타입/린트/빌드도 검증했다. 실행 명령과 범위는 [로컬 개발 안내](../docs/10-local-development.md)에 기록했다. M08에서 40개 조문과 별표 2·3·4의 전체 정리·완전성 검토를 마쳤다. M08A 실제 목록 12개 공간·35개 시설·45개 증상·54개 질문을 검토하고 로컬 개발 DB에 게시했다. M09에서 49개 청크를 실제 OpenAI로 임베딩하고 53건 검색 평가 후 로컬 개발 DB에 게시해 설문 검색을 연결했다. M10에서 회원 챗봇·gpt-5.4-mini Responses·원문 선택/인용 검증·대화 복구를 연결하고 실제 12건 평가를 통과했다. 운영 배포는 후속 단계다.

계획 점검의 삭제 후 재실행 차단은 M06 API·DB와 M07 화면에서 구현·검증했다. M09의 근거 검색·최종 철회 검사는 구현했다. M10 ChatHistory를 구현했다. 백업 복원 후 삭제 재적용은 M11의 작업이다. 범위는 [후속 반영 표](../docs/09-development-standards.md#5-계획-정합성-개정과-후속-반영)를 따른다.

## 1. MVP 완료 범위

완성된 목록으로 비회원/회원 설문과 결과 저장을 제공하고, 회원은 본인 이력과 내부 RAG를 우선 참조하는 챗봇을 이용할 수 있어야 한다. 안내 정보가 부족하면 연락처 없는 직접 문의로 안내한다. 명시적 삭제·3~5년 보존·Docker 배포·백업 복원까지 검증한다.

현재 구성은 TypeScript·React, FastAPI, 단일 PostgreSQL + pgvector, Docker Compose web·api·db, API 1개 워커다. DB 분리·Redis·큐·상시 워커·근사 검색·익명 결과 계정 이전은 [후속 검토 기준](../docs/07-architecture-decisions.md)을 따른다.

## 2. 개발 순서와 상태

순서는 통합 완료 기준이다. M05~M07의 코드·시험 완료와 M08A의 실제 목록 검증을 구분한다. 실제 자료가 완료 기준에 포함된 M08·M08A·M09는 자료 검증을 생략한 채 완료로 표시하지 않는다. M08은 실제 추출 지시가 있으면 착수할 수 있다. M09의 실제 청킹·임베딩은 M08의 전체 정리 검토 완료 뒤에만 실행한다.

시험 fixture는 테스트 전용이며 개발 공개 카탈로그·운영 증상 목록·실제 RAG 지식으로 게시하지 않는다. 법령만 확보한 경우 LH 운영 결론을 임의로 만들어 자료 부족을 채우지 않는다.

## 4. 착수할 작업과 문서 사용

사용자 요청에 따라 완성 목록 작성·검토·실제 게시 검증은 **M08 이후 M08A**로 이동했다. M06 API와 M07 화면, M08 원문 정리 및 M08A 목록 작성·검토·게시·통합 검증을 마쳤다. 로컬 개발 DB에는 m08a-20261004-v2을 게시했다. 전용 합성 fixture는 자동 시험에서만 사용했다. M09는 M08 검토 메모·M08A 목록 대응표를 이어받아 완료했다. 현재 catalogReady·ragReady는 true다. M10 회원 챗봇과 실제 생성 답변 검증도 완료했다. 다음 단계는 M11 보존·삭제·백업과 통합 검증이다. [M10 완료 기록](05-m10-chat-review.md)을 따른다.

진행 상태와 실행 증거는 progress/에서 관리하고 기능 정책·API·DB·RAG·운영 규칙은 docs/ 설계를 기준으로 한다. 세부 설계가 바뀌면 해당 설계와 영향을 받는 작업을 함께 갱신한다. 구조 확장은 [측정 기준](../docs/08-scaling-roadmap.md)에 따라 결정한다.
