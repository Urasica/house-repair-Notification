## 변경과 검증

T-M15-05 완료. 결과의 첫 안내는 ‘지금 할 일’이며 서버 안내/추가 확인 다음에 선택한 주택·위치·증상·답변 라벨을 담은 문의 문장을 제공한다. 복사 실패 시 선택 가능한 읽기 전용 입력으로 수동 복구한다. 자유 입력 설명은 자동 복사에 포함하지 않는다. 긴 입력 내역·출처·보관 안내는 펼침으로 옮겼다. 챗봇 원문/별표는 빈 줄 단위 문단을 나눠 모든 내용을 유지한다.

- 프론트 전체 Vitest 58건 통과. 복사 성공/실패·상황 포함·자유 설명 제외·첫 안내와 펼침 상태 회귀 2건 추가.
- 결과/대화 모의 API E2E PC/모바일 4건 통과. axe WCAG A/AA·44px 조작 영역·가로 넘침 포함.
