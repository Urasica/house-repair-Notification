# 이전 진행 문서 경로 제거와 정식 구조 적용

> 기록 ID: R013 · 기준일: 2026-10-18 · 환경: 저장소 문서·참조·Python 문서 검사
> 관계: R011/R012의 이전 경로·절 링크 호환 정책을 폐기한다. 현재 작업판·자동 색인·정식 증거 기록 구조는 유지한다.
> 당시의 증거 기록이다. [현재 상태와 남은 작업](../current-status.md) · [갱신 방법](../README.md)

## 변경과 범위

사용자 요청에 따라 `progress/` 최상위의 이전 번호 안내 파일 10개를 제거했다. 최상위 Markdown은 `README.md`와 `current-status.md`만 사용한다. 기록은 `records/`, 작성 양식은 `templates/`에 둔다. 이전 경로를 위한 리다이렉트나 호환 파일을 유지하지 않는다.

과거 기록의 ‘남은 작업’ 링크는 현재 작업판의 해당 절로, M13 당시 작업 체크리스트 링크는 R001의 해당 절로 직접 연결했다. 관측 결과·시험 수치·해시는 변경하지 않았다. R011/R012의 호환 경로 유지 설명은 그 시점의 조치이며 현재 정책은 이 기록과 갱신 안내를 따른다.

문서 검사에서는 과거 기록에 허용하던 이전 작업 경로 예외를 제거했다. 최상위에 이전 안내 파일이나 별도 진행 문서를 다시 만들면 참조 유무와 관계없이 실패한다. 정식 `records/`의 번호 파일은 그대로 사용한다.

## 검증

| 검사 | 결과 |
| --- | --- |
| 생성 및 읽기 전용 문서 검사 | Markdown 38개·정식 기록 13개, 색인 일치·파일/절 링크 통과 |
| 검사기 회귀 | 14건 통과; 과거 기록의 이전 경로 참조와 참조 없는 이전 파일 재생성 차단 포함 |
| Ruff 검사·포맷 | 검사기와 시험 파일 통과 |
| 최상위 구조 | 현재 작업판·안내 2개 Markdown 및 records/templates 디렉터리만 존재 |

서비스 코드·실행 환경·현재 배포 판단은 변경하지 않았다. 이 문서의 검사 결과는 앱 회귀나 운영 인수 증거가 아니다.
