# M08A 실제 목록 작성·게시·통합 검증

완료일: 2026-10-04(KST) · 최종 버전: **m08a-20261004-v2** · 검토자: Codex

사용자의 M08A 착수 지시에 따라 [M08에서 확인한 실제 원문](02-m08-source-review.md)을 바탕으로 작성했다. 기존 계획의 잘못된 조문·별표 연결이나 시험 fixture를 실제 자료로 사용하지 않았다. COMPLETE_VERIFIED는 목록·연결·질문·분기 검토 완료이며 사람의 법률 검토나 LH 운영 승인을 뜻하지 않는다.

## 산출물과 근거

[목록 안내·증상별 출처](../../data/catalog/m08a-20261004/README.md), [게시 목록](../../data/catalog/m08a-20261004/catalog.json), [검토 및 조문 대응표](../../data/catalog/m08a-20261004/review.json)에 주택 유형 5개·공간 12개·시설 35개·증상 45개·질문 54개를 기록했다. 제6조의2와 제7~45조 40개 조문, 별표 2·3·4, 제35조제2항의 부칙 적용례를 대응시켰다. 공간 분류·쉬운 표현·동의어는 UX 편집이며 원문 인용 또는 법적 동등성으로 취급하지 않는다.

질문에는 모름 선택을 제공한다. 공간 모름은 시설 선택을 열어 두며 시설·증상 모름도 별도 경로로 수집한다. 누수의 흐르는 물 선택에서 추가 질문이 나타나고 물 자국으로 바꾸면 숨겨진 답을 제거한다. 사용 형태는 법정 전유/공용 판정이 아니고, 재해 맥락은 면책 판단이 아니다. 바닥 구성층 질문은 사업계획승인 **신청일**을 구별한다. 별표 4의 손상 표현과 외부 인용 규정은 관찰 분류에만 사용한다.

명시적인 즉시 위험 답 또는 조명의 타는 흔적·연기/불꽃 답은 SAFETY_PRIORITY로 안내한다. 그 밖의 입력이 완성되어도 LH_OPERATION 근거가 없으므로 NEED_CONFIRMATION을 유지한다. 법령만으로 보수 의무·비용·교체 주기를 확정하지 않는다.

## 검증 결과

- 실제 PostgreSQL + pgvector 전체 백엔드 시험 **178건 통과**(DB 63건, 독립 115건). v2의 공간 연결 보완 후 실제 목록 시험 파일 **57건을 재실행해 통과**했다. 모든 증상·시설/공간 경로·질문 선택지의 도달 가능성, 모름, 조건부 답 제거, 위험 우선, 게시 불변성, 회원/비회원 결과·이력·삭제·재생 차단을 포함한다.
- 프론트 **35건 통과**, 타입 검사·린트·빌드 통과. Docker api/web 빌드와 게시 목록 smoke를 검증했다. 백엔드 및 scripts Ruff 검사와 변경 Python 파일 포맷 검사가 통과했다. 전체 scripts 포맷 검사에서 기존 미변경 scripts/lock_python.py의 빈 줄 1건은 남아 있다.
- 컴퓨터 유즈로 390×844 모바일 화면에서 비회원 누수 설문·분기 답 변경/제거·결과 저장, 로그인 후 비회원 이력 미이전, 회원 결과·이력 상세, 삭제 확인/취소, 키보드 이동과 위험 중단을 확인했다. 가로 넘침이 없었고 저장 뒤 라디오 초점이 유지됐다. 최종 v2의 단지 외부→콘크리트→균열 선택도 실제 화면에서 확인했다.
- 브라우저에서 삭제 최종 실행은 하지 않았다. 실제 삭제 및 DELETED/410 재생 차단은 격리된 PostgreSQL 통합 시험으로, 삭제 후 화면 완료 동작은 DOM 시험으로 검증했다.

UI 검증 중 설문 저장 뒤 초점 유실, 보조 링크의 글자/배경색 충돌, 안전 우선 결과에서 미응답 질문을 반복하는 문제를 수정했다. 초점 복원은 사용자가 다른 곳으로 이동한 경우에는 실행하지 않는다. 안내 엔진은 survey-v2로 올렸으며 SAFETY_PRIORITY/OUT_OF_SCOPE에는 후속 질문을 붙이지 않고 NEED_MORE_INFO 질문은 중복을 제거한다. 기존 저장 결과는 스냅샷으로 보존한다.
