## 변경과 범위

T-M15-01 완료. 인증 조회 객체를 유지한 채 이전 계정의 다른 조회를 제거하고 새 로그인 상태를 알린다. 서버 재확인으로 사용자가 바뀔 때도 새 상태를 게시하기 전에 이전 캐시를 정리한다. 각 화면의 효과가 뒤늦게 새 회원 조회를 제거하던 처리를 없앴다. 만료·로그아웃·계정 변경의 데이터 격리와 상담 자격 초기화는 유지한다.

영향 범위는 인증 상태/공유 훅과 기존 설문 흐름 시험이다. API/DB·외부 전송·의존성 변경은 없다. 이전 서비스·UI·문서·UX 점검 작업은 사용자 지시에 따라 먼저 `c46ea96`으로 커밋했다. 환경 비밀·개인 데이터·로컬 캡처는 포함하지 않았다.

## 검증

- `vitest run src/features/auth/auth.test.tsx src/features/survey/flow.test.tsx`: 34건 통과. 로그인 게이트에서 새로고침 없이 이력 열기 회귀를 추가했고 기존 만료/다른 계정/늦은 응답 격리도 통과했다.
- 테스트 임시 파일은 작업 폴더의 기존 `.cache/node-tmp`를 사용했다. 초기 샌드박스 실행은 임시 파일 누락, 수정 중간 실행은 조회 재시도 순환으로 실패했으며 최종 구현과 위 재검사에서 해결했다.
- 문서 검사와 변경 공백 검사를 통과했다.
