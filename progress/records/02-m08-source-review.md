조문 127개 문단은 앞뒤 공백만 정리하고 원문 전체 문장으로 보존했다. 브라우저 전체 텍스트 및 별도로 보존한 문단 배열과 대조해 비공백 문자·숫자·항/단서/예외 표시가 일치함을 확인했다. 제21조 제목 뒤 공백도 조문 탐지에서 처리했다. 이는 같은 수집 세션의 대조이며 별도 공식 판본 인증은 아니다.

별표는 PDF의 원시 셀과 정리본을 셀별로 비교하고 전체 페이지 이미지를 시각 검토했다. 별표 2는 6행·비고 1개, 별표 3은 8행, 별표 4는 병합 셀을 펼친 7행이다. 공유 셀의 적용 관계·단위·수치·조건을 보존했다. 40개 조문/3개 별표의 완전성 검사 43건 통과, 누락 0건이다. 제45조의 외부 법령 별표 7은 이 고시 별표와 구별했다.

원본에는 브라우저 전체 텍스트·문단 배열·화면 캡처·별표 PDF, 파생 자료에는 표 셀 JSON·추출 텍스트·검토 이미지·정리본·coverage·검토 메모를 보관했다. manifest에 모든 납품 파일의 SHA256을 기록했다. manifest 자체의 해시는 아래에 고정한다.

## 바로잡은 내용과 다음 단계의 검토 사항

1. 제6조의2와 별표 2가 연결된다는 기존 계획을 정정했다. 실제 관계는 **제10조제2항→별표 2**, **제42조제5항→별표 3**, **제43조제2항→별표 4**다.
2. 제35조제2항에는 2025-58호 부칙 제2조의 **2022-08-04 이후 사업계획승인 신청** 조건을 연결했다. 다른 총칙·경과조치도 생략하지 않았다.
3. 별표 4의 ‘파손 및 손상’에는 “파손이 경미하고 추가적인 손상진행의 가능성이 없는 양호한 상태”라고 적혀 있다. 원문 그대로 보존했으며 공식 해석/정정 확인 전 이 행을 자동 하자 판정 규칙으로 사용하지 않는다. 추출 누락과 적용 의미 미확인을 구분했다.
4. 외부 법령·설계기준·규격 인용은 external-references.json에 기록했다. 외부 문서 전체와 현행성은 검증하지 않았고 원문의 기관명·NFSC·KGS 등의 표기를 임의 변경하지 않았다.
5. 자료 종류는 LAW_CRITERIA이며 LH_OPERATION은 미확보다. 실제 주택·사건의 적용 조건, LH 보수 의무·비용·교체 결론을 별도로 검토한다. [상세 메모](../../data/private/m08/2026-10-04/review-notes.md)를 M08A/M09에 인계한다.

M08A의 실제 목록 작성·검토가 다음 단계다. 이번 작업에서 청킹·임베딩·DB 반입·카탈로그 게시·OpenAI 호출은 실행하지 않았다. 앱 코드를 바꾸지 않아 기존 앱 시험을 재실행하지 않았으며 위 자료 무결성 검사를 수행했다.
