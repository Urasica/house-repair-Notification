## 변경과 검증

T-M15-06 완료. 비회원 설문 선택/결과와 홈의 펼침 안내에 현재 창·상담 이용 시간과 서버 보관 기한의 차이를 설명한다. 비회원 상담이 실제로 있을 때 로그인 전에 계정으로 옮겨지지 않고 더 이상 이어볼 수 없음을 알리며 문의 내용 복사를 안내한다. 챗봇은 로그아웃/창 닫기 후 새 대화로 시작함을 설명한다.

가입 성공 후 입력을 메모리에서 기존 로그인 API로 한 번 이어 보내고 목적 화면으로 이동한다. 로그인만 실패하면 이미 가입됐다는 안내와 로그인 화면을 유지하며 비밀번호는 비운다. 기존 API·인증 쿠키·비밀번호 정책은 그대로이고 비밀번호/입력을 새 저장소에 보관하지 않는다.

- 모의 API E2E PC/모바일 가입 성공/실패 4건 통과. 실제 비회원 상담을 먼저 만든 뒤 로그인 전 안내, 재입력 없는 목적 화면 진입, 실패 시 가입 화면 재제출 방지·비밀번호 초기화·이메일 유지 확인.
- 홈/로그인 PC·모바일 및 320/768px 밀도·axe A/AA·44px·가로 넘침 검사를 포함한 2건 통과. 기존 두 시작 버튼의 첫 화면 노출 유지.
- lint·타입·문서·공백 검사 통과. 실제 API E2E의 가입 시나리오도 연속 로그인 흐름으로 갱신했다.

## 한계

비회원 이관·기기 간 대화 보관·비밀번호 저장 기능은 추가하지 않았다. 실패한 로그인은 사용자가 직접 재시도한다. 서비스 재배포와 실제 기기 인수는 미실행이다.
