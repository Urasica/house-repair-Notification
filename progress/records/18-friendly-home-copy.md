# 홈 안내 문구의 말투와 설명 보완

> 기록 ID: R018 · 기준일: 2026-10-19 · 환경: 로컬 소스·Node 22.23.1·Vite·Chromium PC/모바일 에뮬레이션·mock HTTP
> 관계: R017의 간결한 홈 문구를 부드러운 말투와 충분한 설명으로 보완한다. R017의 화면 밀도와 기존 서비스 배포 관측은 유지한다.
> 당시의 증거 기록이다. [현재 상태와 남은 작업](../current-status.md) · [갱신 방법](../README.md)

## 변경과 범위

M14의 T-M14-03: 홈 안내가 지나치게 함축적이고 딱딱하다는 피드백을 반영한다. 함께 살펴보는 말투로 바꾸고 이용 방법을 자연스러운 문장으로 설명하면서 기존 모바일 배치를 유지하는 것이 완료 조건이다.

홈 제목은 ‘집 안의 불편함, 함께 살펴봐요’, 설문 안내는 ‘몇 가지 질문으로 알아봐요’, 챗봇 안내는 ‘챗봇에 편하게 물어보세요’로 바꿨다. 본문에는 ‘로그인 없이도 괜찮아요’, ‘관련 자료를 살펴 안내해 드릴게요’처럼 이용 조건과 안내 내용을 부드럽게 풀어 썼다. 개인정보 입력 주의와 자료 준비 중 안내도 문장으로 설명했다.

회원/비회원의 이용 조건, 기록 보관·삭제·외부 전송 정책, 기능 버튼 이름과 처리, CSS·배치는 변경하지 않았다. 바뀐 문구를 참조하는 기존 E2E와 [기획 기준](../../docs/product/service.md#7-보존-설명과-접근성), [프론트 표시 기준](../../docs/frontend/application.md#7-접근성보안과-인수-조건)을 함께 갱신했다.
