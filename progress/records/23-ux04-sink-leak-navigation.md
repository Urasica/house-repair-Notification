## 변경과 검증

T-M15-04 완료. 화면의 싱크대 항목에 ‘마감’을 명시하고 주방 배관에는 ‘싱크대 아래·수도관 등’을 덧붙였다. 싱크대 마감을 고른 사용자는 ‘싱크대 아래에서 물이 새요’를 눌러 기존 pipe/leak 선택으로 이어갈 수 있다. 카탈로그 버전과 실제 ID 연결이 일치할 때만 노출하며 기존 선택 변경 함수로 하위 답변을 초기화한다. 게시 JSON·법적 기준·백엔드는 변경하지 않았다.

- 실제 게시 JSON을 사용한 모의 API E2E: PC/모바일 2건 통과. 바로가기 후 시설 pipe·증상 leak 확인.
- 표시/연결 Vitest 4건 통과: 실제 카탈로그의 공간 관계·별도 버전·선택 초기화 유지.
- 문서 검사·변경 공백 검사 통과.
