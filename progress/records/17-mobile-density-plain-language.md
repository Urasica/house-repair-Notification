# 모바일 화면 밀도와 쉬운 홈 안내 문장 보완

> 기록 ID: R017 · 기준일: 2026-10-19 · 환경: 로컬 소스·Node 22.23.1·Vite·Vitest/jsdom·Chromium PC/모바일 에뮬레이션·mock HTTP
> 관계: R016의 모바일 크기·간격·홈 문구를 사용자 피드백에 따라 보완한다. R009/R010의 API·서비스 배포 관측을 대체하지 않는다.
> 당시의 증거 기록이다. [현재 상태와 남은 작업](../current-status.md) · [갱신 방법](../README.md)

## 변경 이유와 대상

M14의 T-M14-02: 모바일에서 큰 메뉴·제목·여백과 긴 설명 때문에 주요 행동이 한눈에 들어오지 않는 문제를 줄이고 홈 안내를 모든 연령이 읽기 쉬운 문장으로 바꾼다. 완료 조건은 320/360×800px 기본 화면에서 두 시작 버튼 노출, 44px 이상 조작 영역과 본문 16px 유지, 안내 조건 보존과 PC 회귀 확인이다. 2026-10-19 소스·모의 API 범위에서 완료했다.

600px 이하에서 브랜드·메뉴·제목·카드·진행 단계·선택 라벨·요약 간격을 조정했다. 메뉴의 선택 표시는 옅은 배경과 밑줄로 바꾸고 불필요한 큰 면적을 줄였다. 일반 본문은 16px을 유지하고 조작 영역은 최소 44×44px을 유지했다. 화면 너비에 맞춰 자연스럽게 줄을 바꾸도록 홈의 강제 줄바꿈을 제거했다.

홈은 ‘집 안의 불편을 쉽게 확인하세요’, ‘불편한 곳을 고르면…’ 등 짧은 문장으로 바꾸고 반복 안내를 줄였다. 기록 보관·삭제·OpenAI 전송 안내는 제목이 있는 목록으로 나눴다. 24시간 이용, 상담 이용 시간 종료 후 7일 이내 원문/비회원 결과 삭제, 회원 결과/질문 분류 정보 기본 5년 보관, 기록 삭제 경로, 질문 원문 미전송, 제공자 보관 정책의 별도 적용 조건은 유지한다. 인증·설문·챗봇 처리, API/DB, 게시 자료, 의존성은 변경하지 않았다.

기준: [기획·접근성](../../docs/product/service.md#7-보존-설명과-접근성), [프론트 표시 기준](../../docs/frontend/application.md#7-접근성보안과-인수-조건).

## 화면 비교

360×800px 비회원 홈의 기본 글꼴에서 모의 API로 직접 측정했다. 값은 반올림한 CSS px이며 버튼 위치는 페이지 상단부터 버튼 하단까지의 거리다.

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 브랜드·메뉴 영역 높이 | 136 | 108 |
| 홈 소개 영역 높이 | 350 | 209 |
| 설문 시작 버튼 하단 | 768 | 529 |
| 챗봇 시작 버튼 하단 | 1,037 | 729 |
| 홈 전체 높이 | 1,385 | 1,014 |

두 시작 버튼이 360×800px에서 스크롤 없이 보이며 320×800px에서도 같은 버튼 위치를 확인했다. 확대·기기 글꼴 변경 시의 스크롤 없는 표시까지 보장하는 수치는 아니다.
