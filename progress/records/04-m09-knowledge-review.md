## 검증

전체 백엔드 **201건 통과**(실제 PostgreSQL 시험 69건 포함), Ruff 검사·포맷 검사, api Docker 빌드, Alembic 스키마 차이 없음, 게시 목록/RAG smoke 통과. 프론트 코드는 변경하지 않았으며 M08A의 35건 검증 기록을 유지한다.

추가 시험은 검토 미완료/파일 변조/누락/경로 이탈 차단, 조문·별표·비고 보존, 잘못된 임베딩 모델/차원/NaN/인덱스·429/OFF 거부, 임베딩 재실행/재사용, 운영 조건/충돌, 게시 후 변경 금지, 만료·철회·필수 문맥 누락, 철회 후 재반입 거부, 자유 설명 미전송, 위험 우선·공급자 실패의 대체 안내를 포함한다.

실제 OpenAI 임베딩을 사용하는 **53건 평가**에서 근거 묶음 recall@5 100%, 상태 정확도 100%, 법령의 운영 오적용 0건이었다. 현재 카탈로그 태그/명시적 조문 번호로 후보를 제한한 평가이므로 임의 자유 질문이나 한국어 전반의 성능, small 대비 우월성, 생성 답변 정확도까지 검증한 것은 아니다. 검색 결과의 본문·벡터·연결·검토 지문을 고정한 뒤 게시했다.

최종 로컬 API에서 catalogReady=true·ragReady=true를 확인했다. 실제 누수 설문은 제10조와 별표 2를 RELATED로 인용하고 NEED_CONFIRMATION을 유지하며 동일 requestId 재전송은 200과 같은 결과 ID를 반환한다. 검증용 상담에는 실제 개인정보를 넣지 않았다.

문서 임베딩 16,190토큰, 평가 질문 1,431+1,431+1,473토큰으로 관리 명령에서 확인한 합계 20,525토큰이다. 별표 연결 보완 후 추가 문서 임베딩은 0토큰이다. 최종 설문 API 확인 1회의 질문 임베딩은 이 합계에서 제외한다. 생성 호출은 하지 않았다.

## 검토 한계와 후속

별도의 M09 APPROVED는 원문 설명/관련 법령 참고용 서비스 적격성에 한정한다. M08 전사 검토의 NOT_APPROVED 기록을 바꾸지 않았으며 사람의 법률/LH 운영 승인이 아니다. 외부 인용 규정과 별표 4의 미확인 문구는 적용 설명에서 제외한다. LAW_CRITERIA의 APPLICABLE은 법령 설명만 뒷받침하며 LH 운영 적용을 의미하지 않는다.

LH_OPERATION은 여전히 미확보다. 실제 설문의 운영 판단은 직접 문의를 유지한다. M10에서 회원 챗봇·Responses API·Structured Outputs·생성 출력 검증을 연결하고, M11에서 보존/복원, M12에서 운영 배포를 검증한다. 데이터 공유 혜택의 계정 자격과 설정은 이 작업에서 변경하거나 확인하지 않았다.
