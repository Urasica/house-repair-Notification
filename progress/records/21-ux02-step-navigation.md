## 변경과 검증

T-M15-02 완료. 공통 라우팅에서 앞으로 이동하거나 경로를 교체하면 맨 위로 이동하고 새 화면 제목에 초점을 준다. 자료를 기다리는 화면에서는 제목이 생길 때까지 관찰한 뒤 한 번만 이동한다. 관찰자는 완료/경로 변경 시 해제한다. POP(초기 열기·뒤로/앞으로 가기)는 강제 스크롤/초점을 적용하지 않는다.

기존 UI E2E에 선택 화면 하단에서 설문 이동 후 제목의 실제 뷰포트 노출·초점·스크롤 0 검증을 추가했다. PC/모바일 2건과 같은 과업의 axe WCAG A/AA·44px 조작 영역·가로 넘침 검사가 통과했다. 문서 검사와 `git diff --check` 통과. API/DB/의존성 변경은 없다.

## 한계

뒤로 가기 위치를 별도 저장하는 기능은 추가하지 않았다. 실제 기기·스크린리더와 서비스 재배포는 미실행이다.
