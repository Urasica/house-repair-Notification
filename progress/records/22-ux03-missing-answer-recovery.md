## 변경과 검증

T-M15-03 완료. 필수 무응답이면 평가를 보내지 않고 첫 누락 질문으로 초점을 옮겨 항목별 안내를 표시한다. 필수 답변 개수를 보여 주며 UNKNOWN은 정상 답으로 인정한다. 안전 중단 답변은 기존처럼 저장 후 즉시 평가한다. 누락 결과의 수정은 주택/증상 선택이 갖춰졌다면 설문으로 직접 이동한다. 주택 유형 ‘모름’에는 계약서/입주 안내문과 기관에 물을 문장을 제공한다.

영향은 선택/설문/결과, 공용 주택 안내, 완성 설문 fixture와 회귀다. 법적 기준·API/DB·의존성은 바꾸지 않았다.

- 프론트 전체 Vitest 56건 통과: 누락 전송 차단·UNKNOWN 완료·누락 항목 복귀·모르는 주택 설명 회귀 3건 추가, 기존 안전/재시도/계정 격리 유지.
- 모의 API PC/모바일 설문 E2E 2건 통과: 누락 질문 초점·설문 유지·정상 결과·axe WCAG A/AA·44px 조작 영역·가로 넘침.
- ESLint에서 효과 내 상태 변경을 발견해 복귀 안내 상태를 초기값으로 옮겼다. 최종 lint·타입 검사·문서/공백 검사를 통과했다.
