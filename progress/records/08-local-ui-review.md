## 확인한 문제와 변경

실제 브라우저에서 현관을 선택해도 환기·후드·난방·시공 가전 등을 포함한 22개 시설물이 표시됐다. 공간 필터가 없었던 것이 아니라 게시 카탈로그의 시설물-공간 연결 범위가 넓었다. 화면의 긴 제목 줄바꿈, 단계 표시 부재, 현재 선택을 확인하기 어려운 배치도 확인했다.

- `presentation.ts`에 현행 `m08a-20261004-v2` 전용 탐색 목록을 추가했다. 현관은 모름을 포함한 10개, 주방·욕실 등은 해당 공간의 시설물을 보여준다. 실제 카탈로그 연결 안에서만 선택하며 게시 자료와 서버 판정은 수정하지 않았다.
- 현관문·문틀, 신발장·수납 가구, 욕실 환풍기, 주방 환기·후드처럼 화면 명칭을 공간에 맞췄다. 저장 ID는 유지한다. 기존 저장 선택이 새 탐색 목록에 없으면 ‘이전 선택’으로 표시한다. 다른 카탈로그 버전·공간 모름은 원래 연결을 사용한다.
- 공간 변경 시 시설물·증상·답을 초기화하고 시설물 변경 시 증상·답을 초기화한다. 두 공간에 공통으로 있는 시설물도 이전 답을 끌고 가지 않는다.
- 3단계 진행 표시, 현재 선택 요약, 설문의 공간→시설물→증상 경로, 입력 그룹 간격·라디오 선택 강조·포커스 표시·한글 줄바꿈·반응형 배치를 개선했다. 홈의 개인정보 상세 안내는 펼쳐 읽을 수 있게 정리했다.

첫 비회원 E2E는 평가 처리 중 기본 URL 검사 제한 5초가 먼저 끝났다. 실제 클라이언트 평가 제한 15초에 맞춰 URL 대기를 수정하고 전체 2건 재검증을 통과했다. API 제한이나 응답 처리는 변경하지 않았다. 이번 검증은 기존 개발 환경의 OpenAI 설정을 사용했다.

CUA 화면 증거는 Git 제외 로컬 `artifacts/ui-20261007/entrance-desktop.jpg`, `survey-desktop.jpg`에 저장했다. 브라우저의 반응형 임시 크기는 점검 후 기본값으로 복구했다. 스크린리더·실제 운영 인수와 M12의 남은 조건은 [M12 검토 기록](07-m12-deployment-review.md)을 유지한다.
